# Sean Wenzel Portfolio

This folder is ready to deploy on Vercel.

1. Upload this folder to a new GitHub repository.
2. Sign in at [vercel.com](https://vercel.com) and choose **Add New → Project**.
3. Import that GitHub repository.
4. Leave the framework setting as **Other** and click **Deploy**.

Vercel will provide a free `vercel.app` address. If the name is available, it will be similar to `sean-wenzel-portfolio.vercel.app`.

This deployment folder contains only the public portfolio, résumé, and writing-sample PDFs. It has no controls for changing the sky, portrait, or writing samples.
